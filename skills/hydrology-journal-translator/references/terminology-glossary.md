# Hydrology Terminology

| Chinese | English |
|---|---|
| 流域 | basin / watershed |
| 子流域 | subbasin |
| 水文响应单元 | hydrologic response unit (HRU) |
| 径流 | runoff or streamflow (context dependent) |
| 地表径流 | surface runoff |
| 侧向流 | lateral flow |
| 地下水补给 | groundwater recharge |
| 蒸散发 | evapotranspiration (ET) |
| 潜在蒸散发 | potential evapotranspiration (PET) |
| 率定 | calibration |
| 验证 | validation |
| 预热期 | warm-up period |
| 气候强迫 | climate forcing |
| 土地利用变化 | land-use change |
| 情景贡献分解 | scenario-based contribution decomposition |
| 非加和效应 | non-additive effect |
| 干旱传播 | drought propagation |
| 滞后 | lag |
| 标准化降水蒸散指数 | Standardized Precipitation Evapotranspiration Index (SPEI) |
| 标准化径流指数 | Standardized Streamflow Index (SSI) |
