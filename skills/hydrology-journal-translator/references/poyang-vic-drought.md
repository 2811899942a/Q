# Poyang Lake VIC Drought Translation Knowledge Map

This reference is for translating the Poyang Lake VIC manuscript into English journal style. It is a reasoning map, not a replacement for manuscript evidence.

## 1. Core scientific storyline

A strong Poyang Lake VIC drought manuscript usually follows:

**hydroclimatic anomaly -> catchment water-balance response -> hydrological drought manifestation -> spatial/temporal heterogeneity -> physical interpretation -> implication**

Do not reduce the manuscript to "drought occurred". Identify which hydrological component is being reconstructed or evaluated.

## 2. Evidence layers

Keep these layers separate:

### Meteorological drought

Evidence:
- precipitation deficit;
- SPEI or similar climate indicators;
- atmospheric water-demand anomaly.

### Catchment hydrological response

VIC-supported evidence may include:
- runoff/discharge reconstruction;
- soil moisture;
- evapotranspiration;
- water storage components depending on model configuration.

### Lake drought or lake-level response

Requires lake observations, lake hydrodynamic information, or explicit river-lake coupling evidence.

Do not translate VIC catchment output as direct lake-process proof.

### River-lake interaction

Requires evidence about:
- Yangtze River backflow or hydraulic connection;
- lake outlet/inlet conditions;
- water-level dynamics;
- external regulation effects.

Do not infer these mechanisms from VIC results alone.

## 3. Preferred terminology

Use:

- Poyang Lake Basin;
- hydrological drought;
- meteorological drought;
- soil moisture drought when soil moisture is the indicator;
- streamflow drought when discharge deficits are analyzed;
- lake water-level decline when observations describe lake level;
- drought propagation when lagged transmission is demonstrated.

Avoid using `Poyang Lake drought` as a universal term when the actual evidence refers to a catchment indicator.

## 4. Results writing pattern

Preferred:

indicator -> magnitude -> location/period difference -> event characteristic

Example structure:

`The reconstructed streamflow showed persistent deficits during [period], with longer drought duration and larger severity in [region/event].`

Do not add:

`This was caused by climate change`

unless the analysis directly tests that claim.

## 5. Discussion mechanism pattern

Use:

climate forcing
-> precipitation/evaporative demand change
-> soil water/storage response
-> runoff generation change
-> hydrological drought response

Only include each link when supported by model variables or observations.

## 6. VIC-specific translation rules

Always distinguish:

- simulated vs observed;
- reconstructed vs measured;
- calibrated vs validated;
- model output vs independent evidence.

Preferred:

`VIC successfully reconstructed historical streamflow variability.`

Avoid:

`VIC accurately reproduced the actual hydrological process.`

unless process validation exists.

## 7. Thesis-to-journal conversion logic

For converting a Chinese thesis chapter into an SCI paper:

Remove:
- chronological work description;
- excessive model setup details;
- repeated event descriptions.

Keep:
- strongest drought events;
- strongest spatial contrasts;
- strongest hydrological mechanism;
- evidence supporting the main claim.

## 8. Common reviewer concerns

Check before translation:

- Is the drought definition clear?
- Is the indicator appropriate for the claimed process?
- Are model-derived conclusions separated from observations?
- Are lake dynamics supported by lake evidence?
- Are mechanisms explained using hydrological processes rather than general climate statements?
