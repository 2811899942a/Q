# Section Workflows

## Abstract
Problem -> gap -> method -> evidence -> implication.

## Introduction
Context -> scientific gap -> objective -> contribution.

## Methods
Preserve datasets, resolution, preprocessing, model versions, periods, equations, thresholds, and metrics.

## Results
Evidence first. Report values and patterns; keep mechanisms limited.

## Discussion
Explain physical mechanisms and compare literature.

## Conclusions
Answer research questions without adding new evidence.
