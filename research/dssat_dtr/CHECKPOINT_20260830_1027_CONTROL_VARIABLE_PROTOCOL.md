## 1. 本检查点的优先级
本文件记录用户最新确认的实验边界。若与 `CHECKPOINT_20260830_TEMP_ACCURACY_V2_PRESPEC.md` 中较复杂的验证建议发生冲突，以本文件为准。

## 2. 核心科学问题
在保证现有 DSSAT 输入数据完整、模型能够正确读取并正常运行的前提下，仅改变逐小时温度算法，采用控制变量法检验：
1. 温度模拟精度能否继续提高；
2. 温度算法改变后，玉米产量模拟精度能否同步提高。

不追求石河子试验的完美论文复现，也不继续寻找新的外部气象、土壤、施肥、管理或作物数据。

## 3. 唯一数据基线
后续所有实验全部参考已经冻结的成品包及其现有 GitHub 结果链：
- `DSSAT_M15_Xinjiang_13p5_13p8_Package_v1`
- 最终下边界审查 run：`33259349242`
- 冻结 checkpoint：`ef34289f50d889e15de9df1d0a0323c21b36f20c`
- 项目部署决策 commit：`07ec04abb355f46f76c5a70be1d025ad5ae8ad18`

禁止为了提高结果额外替换数据源、补找论文参数或重新构造 DSSAT 基础输入。

## 4. 最低输入验收门槛
正式比较前只做两个 gate：

### Gate A：数据完整
确认运行所需的天气、土壤、品种、试验/管理文件及产量观测均存在，当前固定案例可以完整运行。

### Gate B：模型正确读取
确认 DSSAT 实际读取目标 WTH/实验文件、日期和处理编号正确，运行成功并产生有效输出；新温度算法确实进入目标代码路径。

Gate A/B 通过后立即进入控制变量实验，不再扩展数据准备工作。

## 5. 控制变量规则
除温度算法外，以下内容在所有实验臂之间保持完全一致：
- 天气日值输入；
- 土壤；
- 品种参数；
- 播期；
- 灌溉；
- 施肥/当前 N_OFF 处理；
- 初始条件；
- DSSAT CERES-Maize 其他源码；
- 产量观测；
- 模拟年份和处理。

每轮优先一次只增加或改变一个温度算法结构，随后再做必要的组合实验。

## 6. 固定对照组
至少保留：
- H0：DSSAT 4.8.5 原始温度路径；
- H1：冻结 M15-13.5，DTRc=13.5 C，alpha=6.407985379809223；
- H2：冻结 M15-13.8，DTRc=13.8 C，alpha=6.749813473189908；
- H3+：新增温度优化候选。

13.5/13.8 冻结版本不得覆盖或静默改写。

## 7. 最终评价标准
研究最终只设两个主评价维度。

### A. 温度精度
主指标：逐小时温度 RMSE（C）。
辅助指标：MAE、Bias、R2，用于诊断，不替代 RMSE 主排序。

冻结基线：
- 原 DSSAT：RMSE = 2.946891175 C；
- M15-13.5：RMSE = 2.796223546 C；
- M15-13.8：RMSE = 2.801548624 C。

### B. 产量精度
主指标：产量 RRMSE（%）。
辅助指标：RMSE、MAE、Bias。

当前 `SRAD19P8_N_OFF` ALL8 冻结基线：
- 原/H0TT：RRMSE = 26.9147158%；
- M15-13.5：RRMSE = 25.4973651%；
- M15-13.8：RRMSE = 24.0122042%。

## 8. 判定方法
不设置人为综合权重。优先寻找同时降低温度 RMSE 和产量 RRMSE 的候选，并保留 Pareto 对比。

若某方案温度更准但产量变差，结果必须保留并记录，不能通过更换输入数据修饰结果。

## 9. GitHub 计算与交接制度
所有后续计算、模拟、脚本和结果均在本研究分支形成可追溯提交。

必须及时落盘的事件包括：
- 新算法结构确定；
- 新参数化方案确定；
- 输入/读取 gate 结果；
- 一轮有效模拟结果；
- 一轮失败及失败原因；
- 候选淘汰/保留决定；
- 最优方案变化；
- 阶段性最终结论。

采用两层交接：
1. `CHECKPOINT_YYYYMMDD_HHMM_*.md`：不可变历史检查点；
2. `HANDOFF_CURRENT_M15_TEMP_V2.md`：滚动更新当前状态，供新对话直接接手。

任何关键结论不得只存在于 ChatGPT 对话中。

## 10. 当前下一步
从冻结 M15-13.5 作为主要结构基准开始，对温度曲线内部结构做低维控制变量优化。每个候选先计算相同温度验证集 RMSE，再在固定 DSSAT 作物案例中计算相同 ALL8 产量 RRMSE，形成统一双指标矩阵。
