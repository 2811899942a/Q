冻结 M15-13.5 / M15-13.8 不改写：

- M15-13.8：DTRc=13.8 C，alpha=6.749813473189908；石河子 ALL8 作物传播诊断中产量 RRMSE 相对 H0TT 改善 10.78%。

## 2. 现有文献给出的可借鉴机制

### Lizaso et al., Field Crops Research, 2017
DOI: 10.1016/j.fcr.2017.09.019

CSM-IXIM 在 CERES 基础上引入：

- 营养期/生殖期分开的热时间函数；
- 超最适温度热胁迫指数；
- 花粉失活与雌雄花期高温响应。

论文结果中吐丝、成熟 RMSE 由 CERES 的 7.9 d / 13.7 d 降至约 2.8 d / 7.3 d，产量 RMSE 由约 1219 降至 1082 kg/ha。

借鉴点：阶段化热时间与生殖期高温损伤可以真正传递到物候和产量。

### Zhang et al., European Journal of Agronomy, 2025/2026
DOI: 10.1016/j.eja.2025.127860

新疆多地点 CERES-Maize 高温研究显示：

- 高温识别使用 Tmax >35 C 且持续 3 d；
- 吐丝—乳熟期 HDD 每增加 1 C d，产量平均下降约 0.6%；
- 乳熟—成熟期每增加 1 C d，产量平均下降约 0.3%。

借鉴点：新疆玉米热敏感性具有明确阶段差异，吐丝—乳熟权重应高于乳熟—成熟。

### Tian et al., Agricultural Water Management, 2026
DOI: 10.1016/j.agwat.2026.110311

EFAST 显示 P1、P2、PHINT、P5 主导物候；P5 是成熟期及产量的重要敏感参数，提示热时间/灌浆持续时间是高杠杆通道。

### Yang et al. / Li Zenglan et al., Remote Sensing, 2023
DOI: 10.3390/rs15123197

通过识别 DSSAT 水分响应不足、构造新胁迫因子、嵌入 CERES 源码、敏感性分析和作物观测验证，地上生物量和产量精度分别提高约 20.39% 和 11.45%。

借鉴点：论文结构应遵循“先证明原模型缺陷 -> 构造有物理意义因子 -> 源码嵌入 -> 敏感性分析 -> 实测验证”。

## 3. V2 核心创新结构

V2 不再尝试用一个指数直接修改 PRFT。核心链条为：

`TMAX/TMIN -> M15 新疆大DTR逐小时温度重构 -> 小时级热量累积与热暴露 -> 生育阶段响应 -> CERES-Maize 物候/结实/灌浆 -> 产量`

### 层 A：冻结 M15 小时温度重构

输出 24 h `T_h^M15`。13.5 为主方案，13.8 为稳健性方案。

M15 的价值是将新疆大日较差条件下同样的 TMAX/TMIN 转化为更合理的小时温度持续时间和日落后降温轨迹。

### 层 B：小时级有效热时间

优先测试使用 M15 的 24 h 温度积分替代仅依赖日尺度近似的极端温度热时间路径：

`DTT_hour = sum_h f_stage(T_h^M15) / 24`

其中 `f_stage()` 采用有上下限、有最适区间的阶段温度响应函数。营养生长期与生殖生长期允许采用不同的固定响应形状，但参数数量严格受控。

这一层负责导师提出的“积温/低温/高温敏感性”中的物候与热量累积部分。

### 层 C：小时级生殖期高温剂量

定义小时热度量：

`HDH_s = sum_h max(0, T_h^M15 - Tcrit_s) * dt`

以 `Tcrit=35 C` 作为新疆文献支持的首个候选阈值，同时进行 33/34/35/36 C 敏感性筛选，最终阈值必须由观测/敏感性而非产量过拟合确定。

与只使用日最高温或日 HDD 相比，HDH 同时包含：

- 超阈值强度；
- 超阈值持续小时数；
- M15 修正后的新疆大 DTR 日内温度轨迹。

阶段权重初始只做文献先验：

- 吐丝—乳熟：`w=1.0`
- 乳熟—成熟：`w=0.5`

该 2:1 比例来自新疆文献 0.6% vs 0.3% / C d 的相对敏感性，仅作为初始先验，后续由区域数据和敏感性分析检验。

### 层 D：单一可迁移区域系数 K_RT

为了满足“换地区只需要重新率定少量温度参数”的项目目标，新增一个主要区域系数：

`K_RT = regional thermal-response coefficient`

首选的高温响应形式：

`F_heat,s = exp(-K_RT * w_s * HDH_s / 24)`

`F_heat,s` 优先施加到生殖期结实/粒数或有效灌浆过程，而不再施加到全季 PRFT。

零参数闭合：`K_RT=0` 时，作物模块必须严格恢复 M15 基线。

低温主要通过小时级热时间函数进入物候路径；只有区域实测显示独立低温生理伤害仍存在时，才新增低温直接胁迫项，避免一开始堆参数。

## 4. 这条路线相对已有论文的差异

已有工作分别覆盖：

- M15：新疆大 DTR 下逐小时温度重构；
- Lizaso/IXIM：阶段热时间 + 生殖高温机制；
- Zhang/Xinjiang：新疆日尺度 HDD 与产量响应；
- EFAST 文献：CERES-Maize 热时间相关参数敏感性。

本研究拟形成的组合贡献是：

**将独立验证过的新疆大 DTR 小时温度重构直接耦合到 CERES-Maize 的阶段热时间和生殖期小时热剂量，使模型能够区分“同样日最高温、不同高温持续时间/日内温度轨迹”的作物响应，并用单一 K_RT 实现区域适应强度迁移。**

这一表述需要后续文献/专利检索继续验证，不提前宣称绝对首创。

## 5. 下一轮实验矩阵

必须同时运行以下四臂，避免直接调最终组合：

1. `M0`：官方 DSSAT 4.8.5；
2. `M15`：冻结 M15-13.5/13.8；
3. `M15 + Hourly-DTT`：只加入小时级阶段热时间；
4. `M15 + Hourly-DTT + HDH/K_RT`：再加入生殖期小时高温剂量。

并另做机制消融：

- HDH-only；
- DTT-only；
- Combined。

主要输出：ADAT、MDAT、HWAM、CWAM、LAIX；有条件时增加 kernel number / grain filling 过程输出。

### 继续/淘汰门槛

- `K_RT=0` 精确闭合 M15：必须 PASS；
- 改进需在独立观测上体现，禁止只看参数扰动幅度；
- 第一阶段目标：产量 RMSE/RRMSE 至少形成 >5% 的稳定改善，并且物候不能明显恶化；
- 若组合模型仍低于约 5% 的独立验证改善，则不包装为核心创新，继续更换作物作用位置或停止此路线。

## 6. 当前结论

PRFT-KT 路线结束。

下一轮主线锁定为：

**M15 小时温度重构 + 小时级阶段热时间 + 生殖期 HDH + 单一 K_RT 区域热响应系数。**

优先在现有可重复基准与石河子/新疆资产上完成机制筛选，再进入乌鲁木齐真实物候/产量率定验证。
