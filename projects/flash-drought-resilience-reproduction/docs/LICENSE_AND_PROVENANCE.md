# License and Provenance

## Paper

The paper is published under **CC BY-NC-ND 4.0**. This project stores original analysis notes and method maps rather than republishing an edited/annotated full-text copy of the article. Link to the Version of Record via DOI.

## Nature supplementary/source files

Official assets are referenced by their publisher URLs in `data/DATA_MANIFEST.md`. Before mirroring binary files into this public GitHub repository, verify the license/rights statement attached to each asset. If redistribution is unclear, keep a downloader + hash manifest and exclude the binary from git.

## Code Ocean capsule

Public availability/exportability does not by itself determine the author's code/data license. The capsule's metadata/license must be inspected before its contents are mirrored into this public repository. Until then, `vendor/codeocean/` contains only provenance instructions.

## Provenance rule

Every externally obtained file must record:

- canonical URL / DOI;
- acquisition date;
- original filename;
- SHA-256;
- file size;
- license or redistribution status;
- whether the file is original, derived, or locally generated.
